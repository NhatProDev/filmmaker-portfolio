A tailor measures the same customer for thirty years. We filmed the last fitting before the shop closed.

Four mornings, one prime lens, and the window the shop has always used. Nothing was added to the room, and the grade holds the shadows where the room keeps them.

The cutting room on the second morning. Two takes survived; this is the one where nobody looked up.
