Private gate — narrow and constrained viewports

The same candidate, rendered at six real viewports. Each frame is its own visible viewport — the keyboard-open frames are short because the keyboard has taken the rest, so what you see is what the visitor can reach without scrolling. Every frame runs the full state machine; the state switch drives all six at once. The desktop file is untouched.

Derivations are computed from each frame's own width and height — nothing is authored per device.
