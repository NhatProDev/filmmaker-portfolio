## Role in this project

This material is external advisory guidance.

Design authority precedence:

1. Approved project-specific design specifications
2. User-provided visual references
3. Human product intent
4. This external design guideline

This guideline must not override explicit project-specific design choices.

In particular, warnings in SKILL.md about common AI design patterns
must be interpreted as warnings against unintentional defaults,
not categorical prohibitions.

The goal is intentionality, not avoidance for its own sake.
