JUSTIFIED_ROWS — narrow-width behaviour

A system test, not a page. Three packing algorithms run the same ordered sequence at the same width so the differences are attributable to the algorithm alone. Every cell keeps its native aspect — nothing is cropped, nothing is reordered. Switch width and count in the tweaks; each column reports its own row metrics, order audit and aspect audit.

The library holds no true 2.39:1 asset, so extreme-aspect geometry is exercised with labelled geometry probes — ruled boxes, not invented imagery.
