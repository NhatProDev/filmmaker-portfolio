Private project gate — two directions

One password field, nothing else. Neither gate renders, fetches or derives any project data — there is no project object in this prototype at all. Use the state tweak to drive both gates through idle, focused, submitting, invalid and handoff, or type and submit to run the sequence live. No authentication logic is prototyped: the submit path is a timed stub that always fails.
